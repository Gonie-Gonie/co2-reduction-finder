# CO2 Reduction Finder v0.1.5

## Changes

- Added level-based retrofit options for wall, roof, floor, and window measures.
- Kept cooling, heating, heat exchange, lighting, hot-water boiler, cool roof, blind, and PV as toggle measures.
- Replaced the placeholder cost estimate with the Python reference retrofit cost formula.
- Added a staged ANN-backed Pareto backend job:
  - 50-sample screening
  - 200-sample boundary re-evaluation
  - 1000-sample final evaluation
- Added UI cancellation for the running Pareto job.
- Appended final Pareto candidates to the user comparison results.
- Added tests for the ported retrofit cost formula.

## Notes

- Pareto search uses the corrected embedded ANN models and Python-style `_1/_2` sample split.
- The current Pareto candidate space covers the full ECM code grid for the selected building type, climate, and era.
- The UI still needs a more polished result table for long Pareto option labels.
