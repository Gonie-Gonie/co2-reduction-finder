# Release Notes

GitHub Release notes are managed here by tag.

- Add or update `docs/release-notes/vX.Y.Z.md` before pushing the matching tag.
- The release workflow uses that markdown file as the GitHub Release body.
- If no matching file exists, the workflow falls back to a short default note.
- Do not start a note with a duplicate product/version H1. GitHub already shows the release title and tag; start with `## Changes`.
